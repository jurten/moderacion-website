# Diseño

Las páginas simulan sitios convencionales para que la clase reconozca la tarea sin aprender una aplicación nueva. Modo Operate en los casos; modo Read en los materiales. Tipografía de sistema, fondos claros para proyección, texto de 16–18 px, anchos contenidos y adaptación a pantallas pequeñas.

El índice usa azul oscuro y acento lima. Cada caso tiene una identidad sencilla: verde para una librería, azul para un portal y violeta para un espacio de trabajo. Las diferencias permiten reconocer qué caso está proyectado.

Las excepciones deliberadas a la buena usabilidad están descritas en materiales/guia-docente.html. No corregirlas como defectos incidentales. La navegación del índice y los materiales sí debe ser clara y legible.

No hay imágenes ni dependencias externas. El contenido de los casos no muestra las consignas, las soluciones ni las observaciones docentes.
